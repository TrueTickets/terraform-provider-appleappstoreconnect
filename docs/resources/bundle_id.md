# appleappstoreconnect_bundle_id (Resource)

Manages a Bundle ID (App ID) in App Store Connect.

Bundle IDs (also known as App IDs) identify an app throughout the Apple
ecosystem. Each Bundle ID uses a reverse-DNS identifier (e.g.,
`com.example.app`) that is unique across all Apple Developer accounts. The
identifier and platform are fixed at creation time; only the name can be
changed afterwards.

## Example Usage

### Basic Example

```hcl
resource "appleappstoreconnect_bundle_id" "example" {
  identifier = "io.truetickets.test.app"
  name       = "Example App"
  platform   = "IOS"
}

output "bundle_id" {
  value = appleappstoreconnect_bundle_id.example.id
}
```

### Universal (iOS + macOS) Bundle ID

```hcl
resource "appleappstoreconnect_bundle_id" "universal" {
  identifier = "io.truetickets.test.universal"
  name       = "Universal App"
  platform   = "UNIVERSAL"
}
```

## Schema

### Required

- `identifier` (String) The reverse-DNS bundle identifier (e.g., 'com.example.app'). This must be unique and cannot be changed after creation.
- `name` (String) The name of the Bundle ID. This is the only attribute that can be modified in place.
- `platform` (String) The platform of the Bundle ID. One of `IOS`, `MAC_OS`, or `UNIVERSAL`. Cannot be changed after creation.

### Optional

- `seed_id` (String) The seed ID (team ID prefix) of the Bundle ID. If omitted, App Store Connect assigns it automatically. Cannot be changed after creation.

### Read-Only

- `id` (String) The unique identifier (resource ID) of the Bundle ID in App Store Connect.

## Import

Bundle IDs can be imported using their App Store Connect resource ID:

```bash
terraform import appleappstoreconnect_bundle_id.example XXXXXXXXXX
```

Where `XXXXXXXXXX` is the Bundle ID's resource ID from App Store Connect (e.g.,
`3T59BU7786`), not the reverse-DNS identifier like `com.example.app`.
